# Security Policy

## Reporting a Vulnerability

If you discover that a prompt in this repository could be used to bypass security controls, exfiltrate data, or cause harm when executed by an AI agent, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please contact the maintainer via [GitHub (@HannahVernon)](https://github.com/HannahVernon) with:

- A description of the vulnerability
- The specific prompt file affected
- Steps to reproduce the issue
- The potential impact
- Any suggested fixes (optional)

You should receive a response within 72 hours.

## Scope

This policy applies to:

- Prompt files in `prompts/`
- Documentation and examples
- Any tooling or scripts added to this repository

## Responsible AI Use

These prompts are designed for **authorized security assessments** of codebases you own or have permission to test. Do not use them to:

- Assess codebases without authorization
- Generate exploit code
- Bypass access controls on systems you don't own
